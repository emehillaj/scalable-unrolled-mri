# Training and evaluation commands for the models in the paper. Run them from the repository root.
#
# train.py writes local_data/results/<anatomy>_<method>_<chans>ch_<num_cascades>casc_<acceleration>x/
# (or local_data/results/<run_name>/ when run_name is set). Add --data_path /path/to/fastMRI if the data
# is not in local_data/datasets/fastMRI/, and --resume to continue an interrupted run. For several GPUs,
# replace "python train.py" with "torchrun --standalone --nproc_per_node=4 train.py" or
# "sbatch scripts/slurm_multigpu.sh". Runs train for max_epochs (200 in the configs); change it with
# --set max_epochs=<N>. checkpoint.pt is overwritten at every save: copy it to keep a given epoch.
#
# evaluate.py writes local_data/results/eval/<tag>.json plus <tag>_slices.npz (and <tag>_volumes.npz
# with --volume_metrics). Knee tables report the high/low-SNR split (snr_high, snr_low); brain tables
# and the pooled knee table of the supplementary report the mean over all slices (pooled). The
# volume-wise tables use the "volumes" entry.
#
# K-space Cold Diffusion is not part of this repository. To train and evaluate it, follow
# https://github.com/GuoyaoShen/K-SapceColdDIffusion and report its results alongside the above.
